# Code of Conduct

## Our standard

Please keep this project respectful, constructive, and inclusive.

Expected behavior:

- Be respectful in language and tone.
- Focus on technical issues, not people.
- Assume good intent and ask clarifying questions.
- Provide actionable feedback.

Unacceptable behavior:

- Harassment, discrimination, or personal attacks.
- Trolling, intimidation, or sustained disruption.
- Sharing private information without permission.

## Scope

This applies to project spaces such as GitHub issues, pull requests, and discussions.

## Enforcement

The maintainer may edit, hide, lock, or remove content that violates this code of conduct.
