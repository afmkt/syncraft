# AI Workspace

This folder contains AI-related development tracks for Syncraft.

## Structure

- `benchmark/` — benchmark protocol, prompts, task catalog, run logs, and analysis script.
- `curl/` — materials for using LLMs via `curl` to author Syncraft regex++ grammar.
- `mcp/` — MCP-related design and implementation notes for exposing grammar tools to agents.

## Current status

- Benchmark scaffold moved to `benchmark/`.
- `curl/` and `mcp/` are prepared as development placeholders.
