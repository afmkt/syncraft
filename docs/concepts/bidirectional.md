# Bidirectional Model

Syncraft treats parsing and generation as two directions of the same grammar.

## Parse direction

- Input text is consumed according to syntax rules.
- Semantic value is produced through mappings (`map`, `bimap`, `to`, `case`).

## Generate direction

- Semantic value is projected back through inverse mappings.
- Generation succeeds only when the value is compatible with grammar constraints.

## Validation

`validate(...)` checks if a value can be generated by the syntax without materializing final text.

## Practical guidance

- Use `bimap` when both directions are explicit and stable.
- Use `to` for structured value models (e.g., dataclasses).
- Keep transformation functions deterministic and side-effect free.
