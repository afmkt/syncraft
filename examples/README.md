# Examples

These examples are intentionally small and runnable.

- `arithmetic_rp.py`: recursive expression grammar using `Syntax.rp`.
- `comma_list.py`: separator parsing with `sep_by`.
- `dataclass_ast.py`: `to(...)`/`bimap(...)` mapping to domain values.

Run from project root:

```bash
source .venv/bin/activate
python examples/arithmetic_rp.py
python examples/comma_list.py
python examples/dataclass_ast.py
```
